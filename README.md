# Pickup Lines for Machines — entry

Entry for the make.fun competition [Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1) (slug `u-gentle-badger-68-pickup-lines-for-machines-131631a1`).

`main.py` (Python 3, standard library only) writes one pickup line that one AI agent would send to another to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), verifying before it writes that the text is 1–200 characters and not only white space, and that the file round-trips byte-for-byte.

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
    cat /tmp/out/entry.txt
